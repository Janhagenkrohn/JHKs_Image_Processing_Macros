# JHKs_Image_Processing_Macros
## Collection of misc image processing macros/scripts (mostly ImageJ or Python) 

This repo collects image processing scripts that I wrote at some point for some research project. You are free to download, modify, and use these scripts in any way you like. However, keep the following in mind:
- Some scripts are associated with published papers, others are not. If they are, this is indicated in the header of the respective script. Please be fair and cite the relevant paper if the script helped you significantly in preparing your own publication.
- The scripts are developed specific, usually narrow, applications. They are generally not tested on a wide variety of raw data formats, operation systems, parameter ranges, etc. Therefore, I can and will not guarantee that the scripts will work on your data. Neither can I guarantee that they are free from bugs. However, if you believe that one of them would be of great use to you with small alteration, feel free to get in contact (Jan-Hagen Krohn, University Hospital Essen, jan-hagen.krohn[at]uk-essen.de). For such an inquiry, please always provide representative example data for development and testing, otherwise I will not be able to help you.
